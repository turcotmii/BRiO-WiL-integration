# BRiO-WiL-integration
Home Assistant Addon for CCEI BRiO WiL integration

This device is very popular in quebec and sold by Trévi. This addon is not official and not affiliated in any way with CCEI nor Trévi.


## Prerequisite
* connect your BRiO WiL pool light on the same network

## Installation guide
* Copy this repo to your custom_components folder in Home assistant
* Restart Home Assistant
* Open Settings > Devices & services
* Find CCEI BRiO WiL Pool Light
* Enter the IP address of your pool light (ex: 192.168.x.x) and press submit
* Enjoy !
